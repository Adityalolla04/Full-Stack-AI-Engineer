## In simple words

Type hints document interfaces; tests and debugging investigate behavior.

## What to understand

Static typing does not validate arbitrary runtime input. Test normal, boundary, and error behavior; read tracebacks from the failing operation outward.

## Think through this example

A function annotated with an integer still needs a boundary policy for text read from CSV.

## Common mistake

Treating annotations as automatic input validation or testing only the happy path.
