## In simple words

Functions are values that can be passed, wrapped, and composed.

## What to understand

Learn closures, argument forwarding, metadata preservation, and when a simple direct call is clearer.

## Think through this example

A timing wrapper adds measurement while retaining the wrapped function's result and errors.

## Common mistake

Changing function behavior accidentally while adding logging.

## Practice yourself

Sketch a timing wrapper's contract and compare it with explicit timing at a call site.
