## In simple words

Classes group state and operations; dataclasses reduce repetitive value-object definitions.

## What to understand

Understand methods, instance attributes, invariants, composition, and representation. Use plain functions when state is unnecessary.

## Think through this example

A StudySession stores topic and duration while aggregation can remain a separate function.

## Common mistake

Creating a class for every small helper or sharing mutable class attributes accidentally.
