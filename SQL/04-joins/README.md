# Joins

[Back to SQL](../README.md) · [Your practice space](practice/README.md)

## In simple words

Joins combine related rows according to matching conditions.

## What to understand

Compare inner, left, full, self, and cross joins; inspect relationship cardinality and duplicate multiplication.

## Think through this example

A left join can keep topics with no study sessions.

## Common mistake

Adding a right-table filter that unintentionally removes unmatched left-join rows.
