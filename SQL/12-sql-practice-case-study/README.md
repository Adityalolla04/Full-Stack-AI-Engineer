## In simple words

A coherent dataset helps connect querying, modeling, and correctness.

## What to understand

Use synthetic users, topics, sessions, and documents; define expected results before writing queries.

## Think through this example

One user with no sessions tests whether a report preserves empty groups.

## Common mistake

Writing queries without a known expected result on a small dataset.

## Practice yourself

Create your own small dataset and write ten queries, one transaction scenario, and one index experiment.

Write your own implementation in `practice/` when ready. No solution or starter code is supplied.

## Recall check
