# Relational Basics and Data Types

[Back to SQL](../README.md) · [Your practice space](practice/README.md)

## In simple words

Relational databases organize records into tables with typed columns.

## What to understand

Understand rows, columns, schemas, keys, nullability, and appropriate numeric/date/text types.

## Think through this example

A study session has one identifier and a duration with a meaningful numeric type.

## Common mistake

Storing every value as text and deferring all correctness to the application.
