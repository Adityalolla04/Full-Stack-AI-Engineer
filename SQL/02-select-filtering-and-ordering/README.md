# SELECT Filtering and Ordering

[Back to SQL](../README.md) · [Your practice space](practice/README.md)

## In simple words

Queries choose columns and rows and establish an explicit result order.

## What to understand

Learn selection, predicates, boolean logic, DISTINCT, ordering, limits, and stable tie-breakers.

## Think through this example

Recent sessions for one user require both a user filter and a defined order.

## Common mistake

Assuming rows have a guaranteed order without ordering them.

## Practice yourself

Describe queries for recent, longest, and unfinished sessions, including tied timestamps.
