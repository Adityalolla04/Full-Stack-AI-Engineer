## In simple words

Real data needs explicit handling of missing values and transformations.

## What to understand

Learn three-valued logic, IS NULL, COALESCE, CASE, date/time zones, and string functions.

## Think through this example

A missing completion time differs from a duration of zero.

## Common mistake

Comparing NULL with ordinary equality or mixing local times without a policy.

## Practice yourself

Specify missing-value handling and timezone rules for weekly study summaries.
