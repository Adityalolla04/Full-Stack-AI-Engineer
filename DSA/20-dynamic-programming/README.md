# Dynamic Programming

[Back to DSA](../README.md) · [Your practice space](practice/README.md)

## In simple words

Remember overlapping subproblem results instead of solving them repeatedly.

## What to understand

Define state, transition, base cases, evaluation order, and final answer. Compare memoization with bottom-up tables.

## Think through this example

For minimum coins, the best answer for an amount depends on smaller amounts reachable by removing one coin.

## Common mistake

Writing a table before explaining what each cell means.

## Practice yourself

Solve minimum coins, climbing stairs, and longest common subsequence; include impossible cases.
