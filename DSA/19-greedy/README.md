# Greedy

[Back to DSA](../README.md) · [Your practice space](practice/README.md)

## In simple words

Choose the best next action according to a rule that has a correctness argument.

## What to understand

A locally attractive decision is not automatically globally optimal; use an exchange argument or find a counterexample.

## Think through this example

For non-overlapping meetings, selecting the earliest finishing compatible meeting leaves room for later meetings.

## Common mistake

Assuming greedy coin selection works for every coin system.

## Practice yourself

Select non-overlapping intervals and compare greedy versus optimal coin choices for 1, 3, 4.
