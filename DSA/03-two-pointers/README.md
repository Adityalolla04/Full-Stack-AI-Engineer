# Two Pointers

[Back to DSA](../README.md) · [Your practice space](practice/README.md)

## In simple words

Two positions let you compare or reorganize a sequence without restarting a scan.

## What to understand

Opposite-end pointers help with sorted pair sums; same-direction pointers can separate read and write positions.

## Think through this example

For sorted values 1, 3, 6, 8 and target 9, the first and last values already match.

## Common mistake

Moving a pointer without explaining which candidates are safely discarded.
