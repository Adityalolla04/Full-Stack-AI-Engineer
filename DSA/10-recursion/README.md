# Recursion

[Back to DSA](../README.md) · [Your practice space](practice/README.md)

## In simple words

Solve a problem through smaller calls until a base case is reached.

## What to understand

Name the shrinking quantity, base case, and return value. Count call-stack space as well as work.

## Think through this example

A sum from 1 to 4 becomes 4 plus the sum to 3, until reaching the base case.

## Common mistake

A base case that cannot be reached, or ignoring Python's recursion-depth limit.

## Practice yourself

Trace recursive factorial and subset generation on paper before writing them yourself.

Write your own implementation in `practice/` when ready. No solution or starter code is supplied.
