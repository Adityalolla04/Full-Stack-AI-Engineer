# Hashing

[Back to DSA](../README.md) · [Your practice space](practice/README.md)

## In simple words

A hash table maps a key to a value so previously seen information can be found quickly.

## What to understand

Understand collisions, equality, hashable keys, and average O(1) lookup versus worst-case O(n).

## Think through this example

For values 4 and 9 with target 13, remember 4 and look for it when 9 arrives.

## Common mistake

Using a set when frequencies or original indices are required.
