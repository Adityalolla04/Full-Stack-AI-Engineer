# Stack and Queue

[Back to DSA](../README.md) · [Your practice space](practice/README.md)

## In simple words

A stack removes the latest item; a queue removes the earliest.

## What to understand

Use a stack for nested structure and a queue for ordered work. Consider deque for efficient operations at both ends in Python.

## Think through this example

The last opening bracket must match the next closing bracket; a job queue instead serves the earliest waiting job.

## Common mistake

Removing from the front of a Python list repeatedly and assuming constant cost.
