# Backtracking

[Back to DSA](../README.md) · [Your practice space](practice/README.md)

## In simple words

Explore a choice, investigate its consequences, and undo it before trying another.

## What to understand

Separate candidates, state, validity checks, and completion conditions. Prune only when correctness is preserved.

## Think through this example

For choosing two topics from three, abandon a branch once it has too many selections.

## Common mistake

Forgetting to undo shared mutable state between branches.

## Practice yourself

Generate combinations and unique permutations; test repeated inputs.
