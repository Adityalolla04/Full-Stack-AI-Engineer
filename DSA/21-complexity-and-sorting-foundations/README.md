## In simple words

Complexity describes how resource use grows with input size.

## What to understand

Compare O(1), O(log n), O(n), O(n log n), and O(n squared); distinguish worst-case, average, and amortized costs.

## Think through this example

Doubling a quadratic input can roughly quadruple work, while a linear scan roughly doubles.

## Common mistake

Ignoring hidden copying, recursion depth, or output size.

## Practice yourself
