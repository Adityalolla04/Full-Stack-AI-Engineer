# Trees and BST

[Back to DSA](../README.md) · [Your practice space](practice/README.md)

## In simple words

Trees model hierarchies; a BST additionally orders descendants around each node.

## What to understand

Learn preorder, inorder, postorder, and level-order traversal. BST rules apply across entire subtrees.

## Think through this example

A value smaller than the root is invalid anywhere in its right subtree, even beneath a larger child.

## Common mistake

Checking only immediate children or assuming every BST is balanced.

## Practice yourself

Validate a BST and compute tree height; include a deep violation and a skewed tree.
