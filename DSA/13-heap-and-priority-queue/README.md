# Heap and Priority Queue

[Back to DSA](../README.md) · [Your practice space](practice/README.md)

## In simple words

A heap keeps the most urgent item easy to access without sorting every item.

## What to understand

A binary heap supports O(log n) insertion/removal and O(1) root lookup. Define deterministic tie-breaking.

## Think through this example

A scheduler can process priority 1 before priority 3, preserving arrival order among equal priorities.

## Common mistake

Assuming the backing array is completely sorted.
