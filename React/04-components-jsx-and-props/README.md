# Components JSX and Props

[Back to React](../README.md) · [Your practice space](practice/README.md)

## In simple words

React components describe UI from inputs and state.

## What to understand

JSX expresses element structure; props pass data down. Keep rendering predictable and avoid side effects during render.

## Think through this example

A topic card receives a topic name and total minutes from its parent.

## Common mistake

Mutating props or triggering network calls while rendering.
