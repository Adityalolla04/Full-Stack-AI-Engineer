# Routing and API Integration

[Back to React](../README.md) · [Your practice space](practice/README.md)

## In simple words

Routing maps URLs to screens while data requests connect screens to the backend.

## What to understand

Plan direct navigation, parameters, not-found states, request cancellation, stale responses, and authentication expiry.

## Think through this example

Reloading a document detail URL should still resolve the intended screen.

## Common mistake

Treating a hidden route as backend access control.

## Practice yourself

Draw login-to-document navigation and handle failed or out-of-order requests.
