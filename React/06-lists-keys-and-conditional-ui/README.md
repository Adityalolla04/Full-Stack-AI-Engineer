# Lists Keys and Conditional UI

[Back to React](../README.md) · [Your practice space](practice/README.md)

## In simple words

Lists and conditions determine which elements appear and retain identity.

## What to understand

Use stable keys based on data identity; render loading, empty, success, and error states deliberately.

## Think through this example

Reordering editable rows should preserve each row's own input state.

## Common mistake

Using array indices as keys when rows can move or be inserted.

## Practice yourself

Design a reorderable topic list and define its empty/error states.
