## In simple words

TypeScript checks intended JavaScript interfaces before runtime.

## What to understand

Learn object types, unions, narrowing, generics, and component/API contracts; runtime validation remains separate.

## Think through this example

An API payload needs actual validation even if a local interface describes its expected shape.

## Common mistake

Treating a type assertion as proof that external data is valid.
