## In simple words

Trees partition feature space; ensembles combine trees to improve predictions.

## What to understand

Compare depth, pruning, bagging, feature sampling, and sequential error correction in boosting.

## Think through this example

A single deep tree may overfit while an ensemble can reduce certain errors at additional cost.

## Common mistake

Assuming feature importance proves causal influence.
