## In simple words

Linear regression predicts a numeric outcome; logistic regression models class probability through a link function.

## What to understand

Study loss, assumptions, regularization, scaling, optimization, and threshold selection.

## Think through this example

Predicting minutes is regression; predicting whether a session finishes is classification.

## Common mistake

Calling logistic regression a continuous-target model because of its name.
