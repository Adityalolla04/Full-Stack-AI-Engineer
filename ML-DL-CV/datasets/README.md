# Shared existing dataset

`tested.csv` is the original dataset from the imported ML_From_Scratch folder. It is stored once and referenced by the linear regression, logistic regression, decision tree, k-means, and neural-network notebooks.

Open those notebooks with their own folder as the working directory. Their dataset reference is now `../../../datasets/tested.csv`. The dataset bytes were not changed; see the [import manifest](../../docs/import-manifest.csv) for provenance.
