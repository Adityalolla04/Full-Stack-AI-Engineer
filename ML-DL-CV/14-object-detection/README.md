# Object Detection

[Back to ML-DL-CV](../README.md) · [Your practice space](practice/README.md)

## In simple words

Detection identifies both category and location of objects.

## What to understand

Learn bounding boxes, IoU, matching, confidence thresholds, non-maximum suppression, and mAP conventions.

## Think through this example

A correct class with a poorly located box may still be a failed detection.

## Common mistake

Comparing mAP values without matching thresholds, datasets, and evaluation definitions.

## Practice yourself
