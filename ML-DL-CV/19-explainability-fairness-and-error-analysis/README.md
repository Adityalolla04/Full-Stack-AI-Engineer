## In simple words

Investigate where a model fails and whom those failures affect.

## What to understand

Compare subgroup performance, label quality, feature attribution limitations, and distribution slices.

## Think through this example

An acceptable average can hide poor performance on one camera type or user group.

## Common mistake

Treating an attribution chart as a causal explanation.
