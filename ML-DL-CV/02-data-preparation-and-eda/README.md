## In simple words

Understand the data before fitting a model.

## What to understand

Inspect missingness, duplicates, label quality, distributions, group structure, imbalance, and target leakage.

## Think through this example

Multiple records from one person may need to stay in the same split.

## Common mistake

Cleaning or selecting features using information from the final test set.
