# Prometheus

[Back to DevOps](../README.md) · [Your practice space](practice/README.md)

## In simple words

Prometheus collects time-series metrics for querying and alerting.

## What to understand

Know counters, gauges, histograms, labels, scrape targets, and alert rules.

## Think through this example

A request counter tracks volume while a latency histogram supports percentile estimation.

## Common mistake

Using user IDs as metric labels and creating unbounded cardinality.

## Practice yourself

Choose metrics and low-cardinality labels for an ingestion API.
