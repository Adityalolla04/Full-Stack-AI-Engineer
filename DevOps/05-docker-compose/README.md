# Docker Compose

[Back to DevOps](../README.md) · [Your practice space](practice/README.md)

## In simple words

Compose describes a group of local services and their connections.

## What to understand

Understand services, networks, volumes, environment configuration, and readiness versus start order.

## Think through this example

An API and database can share a private network while only the API is exposed to the host.

## Common mistake

Assuming start order guarantees the database is ready.

## Practice yourself

Plan a local API/database/worker setup and its restart behavior.
