# Kubernetes

[Back to DevOps](../README.md) · [Your practice space](practice/README.md)

## In simple words

Kubernetes reconciles declared workloads with a cluster's current state.

## What to understand

Learn pods, deployments, services, configuration, secrets, probes, requests/limits, and persistent storage.

## Think through this example

A deployment replaces a failed pod while a service provides a stable routing target.

## Common mistake

Adding Kubernetes before understanding container lifecycle and operational needs.

## Practice yourself

Sketch a two-replica API with readiness checks and resource requests.

Write your own implementation in `practice/` when ready. No solution or starter code is supplied.
