# ELK Logging

[Back to DevOps](../README.md) · [Your practice space](practice/README.md)

## In simple words

Elasticsearch, Logstash, and Kibana form a log-processing and search stack.

## What to understand

Understand structured logs, collection, indexing, retention, access control, and search cost.

## Think through this example

A request ID links API and worker logs during an incident.

## Common mistake

Indexing every field or keeping sensitive raw content indefinitely.

## Practice yourself

Define a minimal log schema, retention policy, and investigation query in words.

Write your own implementation in `practice/` when ready. No solution or starter code is supplied.
