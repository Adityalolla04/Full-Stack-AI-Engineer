# Terraform

[Back to DevOps](../README.md) · [Your practice space](practice/README.md)

## In simple words

Terraform manages infrastructure through declarative configuration and tracked state.

## What to understand

Understand plan versus apply, state storage, locking, drift, and resource lifecycle.

## Think through this example

A plan describes the difference between declared and observed infrastructure.

## Common mistake

Treating state as harmless metadata or applying a destructive plan without review.

## Practice yourself

Describe how two collaborators share state safely and review a hypothetical change plan.

Write your own implementation in `practice/` when ready. No solution or starter code is supplied.
