# AWS Cloud

[Back to DevOps](../README.md) · [Your practice space](practice/README.md)

## In simple words

Cloud services provide compute, storage, networking, and managed infrastructure.

## What to understand

Learn regions, availability zones, IAM, VPC concepts, object storage, databases, budgets, and shared responsibility.

## Think through this example

A simple API might use managed compute, a relational database, and private object storage.

## Common mistake

Provisioning services without understanding ongoing cost or access permissions.

## Practice yourself

Draw a small deployment and identify its identity boundaries and cost drivers.

Write your own implementation in `practice/` when ready. No solution or starter code is supplied.

## Recall check

- Explain the concept without reading the note.
- Explain why it fits the example and when you would choose something else.
- Describe one boundary or failure case before implementing.
