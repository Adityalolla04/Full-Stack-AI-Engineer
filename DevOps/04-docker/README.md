## In simple words

A container runs an application with packaged dependencies and isolated runtime settings.

## What to understand

Distinguish image from container, layers from writable state, volumes from image files, and build-time from runtime configuration.

## Think through this example

A database file inside a disposable container needs deliberate persistent storage.

## Common mistake

Embedding secrets in image layers or assuming containers are virtual machines.
