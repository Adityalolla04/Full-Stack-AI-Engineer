# Linux and Bash

[Back to DevOps](../README.md) · [Your practice space](practice/README.md)

## In simple words

Linux provides the operating environment; a shell controls processes and files.

## What to understand

Learn paths, permissions, standard streams, environment variables, pipes, exit codes, and process signals.

## Think through this example

A failed program communicates through its exit status as well as its output.

## Common mistake

Assuming Windows PowerShell and Bash have identical syntax.

## Practice yourself

Write a command plan for locating logs, checking permissions, and diagnosing a failed process; execute it yourself later.
