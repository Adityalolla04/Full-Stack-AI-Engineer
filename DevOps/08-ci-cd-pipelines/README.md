# CI CD Pipelines

[Back to DevOps](../README.md) · [Your practice space](practice/README.md)

## In simple words

CI checks integrated changes; delivery/deployment pipelines prepare or release artifacts.

## What to understand

Separate tests, builds, security checks, artifact promotion, environment configuration, and rollback.

## Think through this example

One tested immutable artifact can be promoted across environments.

## Common mistake

Rebuilding different artifacts for each stage without tracking provenance.
