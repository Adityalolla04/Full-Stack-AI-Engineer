# Git and GitHub

[Back to DevOps](../README.md) · [Your practice space](practice/README.md)

## In simple words

Git versions local changes; GitHub hosts repositories and collaboration workflows.

## What to understand

Learn working tree, staging, commits, branches, merges, remotes, reviews, and conflict resolution.

## Think through this example

A local commit exists independently of whether it has been pushed.

## Common mistake

Confusing copying a folder with preserving its Git history.

## Practice yourself

Plan a feature branch, review, and merge workflow; explain how to undo a published change safely.

Write your own implementation in `practice/` when ready. No solution or starter code is supplied.
