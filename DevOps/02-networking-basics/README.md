# Networking Basics

[Back to DevOps](../README.md) · [Your practice space](practice/README.md)

## In simple words

Networking connects processes through addresses, names, ports, and protocols.

## What to understand

Understand DNS, IP, TCP/UDP, HTTP, TLS, routing, and firewalls in a request path.

## Think through this example

A hostname can resolve correctly while the target port is blocked.

## Common mistake

Treating every connectivity failure as an application bug.

## Practice yourself
