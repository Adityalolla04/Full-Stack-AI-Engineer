# Nginx Reverse Proxy

[Back to DevOps](../README.md) · [Your practice space](practice/README.md)

## In simple words

A reverse proxy accepts client requests and forwards them to upstream services.

## What to understand

Study TLS termination, routing, headers, timeouts, upload limits, and trusted proxy settings.

## Think through this example

The proxy serves static assets and forwards API requests to the application.

## Common mistake

Trusting forwarded headers from arbitrary clients.

## Practice yourself

Draw proxy-to-application flow and choose request-size and timeout limits.
