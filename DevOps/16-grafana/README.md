# Grafana

[Back to DevOps](../README.md) · [Your practice space](practice/README.md)

## In simple words

Grafana visualizes data from monitoring sources and supports operational investigation.

## What to understand

Build dashboards around service objectives and actionable questions, not maximum panel count.

## Think through this example

An error spike next to deployment events helps focus investigation.

## Common mistake

Displaying averages alone when tail latency affects users.

## Practice yourself

Sketch a dashboard for traffic, errors, latency, and saturation.

Write your own implementation in `practice/` when ready. No solution or starter code is supplied.
