# GitHub Actions

[Back to DevOps](../README.md) · [Your practice space](practice/README.md)

## In simple words

Actions runs workflows triggered by repository events.

## What to understand

Understand jobs, steps, runners, permissions, artifacts, caching, and protected environments.

## Think through this example

A pull request runs checks without receiving production credentials.

## Common mistake

Granting broad write permissions or exposing secrets to untrusted workflow inputs.

## Practice yourself

Outline a pull-request validation workflow and a separate release workflow.
