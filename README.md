## Inside each concept

Most numbered folders contain a `README.md` with key ideas and a practice task, plus a `practice/README.md` for recording your attempt. Python is organized a little differently: each lesson has notes and a runnable example file.

The seven screenshot tracks retain screenshot numbering. The [learning roadmap](docs/ROADMAP.md) supplies the prerequisite-based study sequence. Start with DSA complexity foundations before its patterns.

## Start learning

1. Read the [roadmap](docs/ROADMAP.md) and [first seven sessions](docs/study-guides/START-HERE.md).
2. Open one concept and explain its example without looking.
3. Write your implementation in its `practice/` folder, or add to the Python lesson file.
4. Record failures, lessons, and review dates.
5. Update [progress](docs/PROGRESS.md); connect your learning in the capstone.
