## Inside each concept

Each numbered folder contains a `README.md`: simple explanation, key ideas, a worked-through scenario, common mistake, practice task, recall questions, and reference. Its `practice/README.md` is for recording your attempt. Create your own solution files there when ready; no generated solutions or starter code are included.

The seven screenshot tracks retain screenshot numbering. The [learning roadmap](docs/ROADMAP.md) supplies the prerequisite-based study sequence. Start with DSA complexity foundations before its patterns.
