# Tokens and Context Window

[Back to LLM](../README.md) · [Your practice space](practice/README.md)

## In simple words

Models operate on tokens and have limits on usable context and generation.

## What to understand

Budget instructions, conversation, retrieved passages, tool results, and output. Tokenization depends on the model.

## Think through this example

A long document may crowd out relevant passages even before the hard context limit.

## Common mistake

Equating tokens with words or blindly truncating important instructions.

## Practice yourself

Plan a context budget and decide what to summarize, retrieve, or omit.

Write your own implementation in `practice/` when ready. No solution or starter code is supplied.
