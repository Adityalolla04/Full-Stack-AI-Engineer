# RAG Pipelines

[Back to LLM](../README.md) · [Your practice space](practice/README.md)

## In simple words

Retrieval-augmented generation fetches evidence before asking a model to answer.

## What to understand

Separate ingestion, retrieval, context assembly, generation, citations, and evaluation. Diagnose retrieval and answer errors separately.

## Think through this example

A policy question retrieves the relevant policy passage and links the answer to it.

## Common mistake

Believing retrieval removes hallucinations automatically.

## Practice yourself

Draw the pipeline and specify behavior for missing evidence and conflicting sources.
