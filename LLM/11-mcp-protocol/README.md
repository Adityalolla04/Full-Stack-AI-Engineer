# MCP Protocol

[Back to LLM](../README.md) · [Your practice space](practice/README.md)

## In simple words

MCP standardizes interactions between AI applications and external capabilities.

## What to understand

Distinguish host, client, server, tools, resources, and prompts; consult the current specification for transport and authorization details.

## Think through this example

A host discovers a server's document-search tool instead of hardcoding a custom integration shape.

## Common mistake

Assuming protocol compatibility makes a server or returned content trustworthy.

## Practice yourself
