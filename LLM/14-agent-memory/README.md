# Agent Memory

[Back to LLM](../README.md) · [Your practice space](practice/README.md)

## In simple words

Memory persists selected information beyond the current interaction.

## What to understand

Separate transient state, user preferences, summaries, and retrieved long-term records; define retention and correction.

## Think through this example

A preferred answer format may persist, while sensitive document text need not be stored as a preference.

## Common mistake

Persisting every interaction indefinitely or mixing users' memories.

## Practice yourself

Design memory scope, expiry, deletion, and contradiction handling.
