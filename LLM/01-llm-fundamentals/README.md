## In simple words

A language model predicts token sequences from learned patterns and provided context.

## What to understand

Separate pretraining, instruction tuning, inference, and retrieval. Fluent generation is not proof of factual correctness.

## Think through this example

A model may produce a convincing answer to a question absent from its evidence.

## Common mistake

Assuming model confidence or tone is a reliability measure.
