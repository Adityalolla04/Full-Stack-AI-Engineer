# Guardrails

[Back to LLM](../README.md) · [Your practice space](practice/README.md)

## In simple words

Guardrails apply validation and policy checks around model behavior.

## What to understand

Use layered input/output checks, permission enforcement, isolation, and monitoring. No text filter guarantees complete protection.

## Think through this example

A tool may reject a request outside the user's allowed document collection regardless of model wording.

## Common mistake

Relying solely on a prompt that says not to do harmful actions.
