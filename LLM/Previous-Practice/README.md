# NLP to Agentic AI: The Master Roadmap (2026)
This repository contains a step-by-step implementation of NLP concepts, following the DeepLearning.AI methodology, leading up to production-grade Agentic AI systems.

## 🧭 The Learning Path
1. **[NLP Foundations](./01-nlp-foundations)**: Vector spaces, Logistic Regression for Sentiment.
2. **[Probabilistic NLP](./02-probabilistic-nlp)**: N-grams, Autocorrect, and Markov Models.
3. **[Sequence Models](./03-sequence-models)**: RNNs, LSTMs, and GRUs.
4. **[Attention & Transformers](./04-attention-transformers)**: Self-Attention, BERT, T5, and GPT.
5. **[Small Language Models (SLM)](./05-slm-specialization)**: Local deployment with Phi-4.
6. **[LangChain Orchestration](./06-langchain-orchestration)**: Chains, Memory, and RAG.
7. **[MCP Integration](./07-mcp-integration)**: Connecting LLMs to local/external data protocols.
8. **[Agentic Design Patterns](./08-agentic-design-patterns)**: Reflection, Tools, and Multi-Agent Teams.
9. **[Capstone Project](./09-capstone-regulation-navigator)**: Building the "Regulation Navigator."
