# Vector Databases

[Back to LLM](../README.md) · [Your practice space](practice/README.md)

## In simple words

A vector store supports similarity search, often with metadata filters and approximate indexes.

## What to understand

Understand recall/latency tradeoffs, indexing, updates, deletion, and permission filters.

## Think through this example

Restrict candidates to the current tenant before returning relevant document chunks.

## Common mistake

Assuming approximate nearest-neighbor search returns the mathematically exact best matches.

## Practice yourself
