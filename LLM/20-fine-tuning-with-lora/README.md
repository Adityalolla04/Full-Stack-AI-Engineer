# Fine Tuning with LoRA

[Back to LLM](../README.md) · [Your practice space](practice/README.md)

## In simple words

LoRA adapts selected model weights through trainable low-rank updates.

## What to understand

Learn the frozen base, adapter rank, target layers, training data quality, and evaluation split. Fine-tuning is not a live knowledge database.

## Think through this example

An adapter can teach a domain response style while retrieval supplies changing documents.

## Common mistake

Training on held-out evaluation examples or fine-tuning before establishing a baseline.
