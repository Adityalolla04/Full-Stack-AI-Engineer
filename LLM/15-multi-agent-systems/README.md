# Multi Agent Systems

[Back to LLM](../README.md) · [Your practice space](practice/README.md)

## In simple words

Multiple agents divide work across roles or independent attempts.

## What to understand

Compare with one agent and deterministic workflows. Define ownership, shared state, coordination, and conflict resolution.

## Think through this example

Separate retrieval and verification roles may help only if verification checks actual evidence.

## Common mistake

Adding more agents without measuring accuracy, latency, and cost.

## Practice yourself

Design a controlled single-agent versus multi-agent comparison.
