# Embeddings

[Back to LLM](../README.md) · [Your practice space](practice/README.md)

## In simple words

Embeddings represent items as numerical vectors for similarity comparisons.

## What to understand

Know what unit is embedded, vector dimensions, normalization, and similarity measure. Similarity is not identity or authorization.

## Think through this example

Two differently worded questions about login may be nearby in vector space.

## Common mistake

Mixing incompatible embedding models in one index without re-embedding.
