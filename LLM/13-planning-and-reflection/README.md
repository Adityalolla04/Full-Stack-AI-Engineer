# Planning and Reflection

[Back to LLM](../README.md) · [Your practice space](practice/README.md)

## In simple words

Planning breaks a task into steps; reflection checks results against requirements.

## What to understand

Replanning should respond to evidence. Extra model passes may add cost without improving correctness.

## Think through this example

After a failed retrieval, revise the query rather than repeatedly issuing the same request.

## Common mistake

Treating a model's self-approval as independent validation.

## Practice yourself

Create a checklist-based review stage with an external success criterion.
