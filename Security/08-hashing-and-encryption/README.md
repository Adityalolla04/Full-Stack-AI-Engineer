# Hashing and Encryption

[Back to Security](../README.md) · [Your practice space](practice/README.md)

## In simple words

Hashing produces a digest; encryption protects confidentiality with keys.

## What to understand

Separate integrity checks, authenticated encryption, signatures, and password hashing. Choose maintained cryptographic libraries.

## Think through this example

A file digest can detect changes but cannot hide the file's contents.

## Common mistake

Inventing a custom cipher or calling encoding encryption.
