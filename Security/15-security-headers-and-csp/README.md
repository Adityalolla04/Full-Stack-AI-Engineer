# Security Headers and CSP

[Back to Security](../README.md) · [Your practice space](practice/README.md)

## In simple words

Browser security headers constrain browser behavior and reduce certain attack paths.

## What to understand

Understand CSP directives, clickjacking restrictions, MIME sniffing protection, and HTTPS-related policies.

## Think through this example

A restrictive script policy can reduce the impact of unexpected script injection.

## Common mistake

Deploying a policy without checking application compatibility or treating it as the only XSS control.
