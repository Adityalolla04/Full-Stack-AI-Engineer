# OWASP Top 10

[Back to Security](../README.md) · [Your practice space](practice/README.md)

## In simple words

The OWASP Top 10 is an awareness guide to major web application risk categories.

## What to understand

Use it to organize threat discussion, then use concrete verification requirements and controls. It is not an exhaustive security test plan.

## Think through this example

A document app needs checks for access control, injection, configuration, and dependency risks.

## Common mistake

Treating a checklist completion as proof that an application is secure.

## Practice yourself

Map your planned app's entry points and data stores to relevant risk categories.

Write your own implementation in `practice/` when ready. No solution or starter code is supplied.
