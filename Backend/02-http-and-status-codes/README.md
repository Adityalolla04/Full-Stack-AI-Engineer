# HTTP and Status Codes

[Back to Backend](../README.md) · [Your practice space](practice/README.md)

## In simple words

HTTP defines how clients request resources and servers respond.

## What to understand

Understand methods, headers, bodies, status families, connection behavior, and HTTPS. Distinguish authentication failure from permission denial.

## Think through this example

A successful creation can return 201; a missing item can return 404.

## Common mistake

Returning 200 for every failure and forcing clients to parse arbitrary text.

## Practice yourself

Trace one browser request and choose statuses for five success/error cases.
