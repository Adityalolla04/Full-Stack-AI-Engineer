# API Versioning

[Back to Backend](../README.md) · [Your practice space](practice/README.md)

## In simple words

Versioning manages changes to an API contract used by existing clients.

## What to understand

Distinguish additive compatible changes from breaking ones; communicate deprecation and migration periods.

## Think through this example

Adding an optional response field differs from renaming a required field.

## Common mistake

Creating a new version for every internal implementation change.
