# DRY KISS YAGNI

[Back to LLD](../README.md) · [Your practice space](practice/README.md)

## In simple words

Avoid duplicated knowledge, unnecessary complexity, and features with no present requirement.

## What to understand

DRY concerns one source of truth; KISS favors a simple working design; YAGNI postpones speculative functionality.

## Think through this example

One documented validation rule is easier to maintain than three slightly different copies.

## Common mistake

Merging unrelated logic because it looks similar today.
