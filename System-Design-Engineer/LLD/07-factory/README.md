# Factory

[Back to LLD](../README.md) · [Your practice space](practice/README.md)

## In simple words

A factory separates object creation decisions from object use.

## What to understand

A simple factory selects concrete objects; Factory Method lets subclasses customize creation. Understand that distinction.

## Think through this example

Choose a PDF or text parser while callers use the same parsing contract.

## Common mistake

Embedding provider selection conditionals throughout the application.

## Practice yourself

Design parser creation for two formats and describe how a third format is added.

Write your own implementation in `practice/` when ready. No solution or starter code is supplied.
