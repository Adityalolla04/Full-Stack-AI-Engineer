## In simple words

OOP groups state and behavior around clear responsibilities.

## What to understand

Encapsulation protects invariants; abstraction hides detail; inheritance expresses specialization; polymorphism permits interchangeable behavior.

## Think through this example

Different notification senders expose the same sending operation while keeping delivery details separate.

## Common mistake

Creating inheritance hierarchies solely to reuse a few lines.
