## In simple words

Create an object by copying an existing configured object.

## What to understand

Distinguish shallow copies, deep copies, and shared resources that should not be copied.

## Think through this example

Two lesson templates can share immutable labels but need independent mutable task lists.

## Common mistake

Assuming a shallow copy isolates nested lists.

## Practice yourself

Explain how to clone a study plan without sharing editable tasks.
