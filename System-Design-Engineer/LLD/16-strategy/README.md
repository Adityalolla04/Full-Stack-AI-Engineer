# Strategy

[Back to LLD](../README.md) · [Your practice space](practice/README.md)

## In simple words

Encapsulate interchangeable ways to perform one operation.

## What to understand

Choose a strategy through a common contract; simple functions may be sufficient.

## Think through this example

Keyword retrieval and vector retrieval provide different ways to find relevant documents.

## Common mistake

Adding strategy classes where there is no useful variation.

## Practice yourself

Compare two ranking strategies using the same input/output contract.
