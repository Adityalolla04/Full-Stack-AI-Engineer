# Adapter

[Back to LLD](../README.md) · [Your practice space](practice/README.md)

## In simple words

Translate one interface into another that a caller expects.

## What to understand

Keep translation at the boundary and preserve meaningful errors and units.

## Think through this example

Two model providers return different response shapes; adapters expose one local response contract.

## Common mistake

Losing error information or confusing adaptation with adding unrelated features.

## Practice yourself
