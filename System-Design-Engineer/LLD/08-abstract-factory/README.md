# Abstract Factory

[Back to LLD](../README.md) · [Your practice space](practice/README.md)

## In simple words

An abstract factory creates related families of compatible objects.

## What to understand

Keep the family consistent behind shared product interfaces. It is useful when several related products vary together.

## Think through this example

A provider family may create a compatible tokenizer, embedding client, and generator.

## Common mistake

Using a family factory when only one simple object varies.
