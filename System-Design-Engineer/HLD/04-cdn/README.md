# CDN

[Back to HLD](../README.md) · [Your practice space](practice/README.md)

## In simple words

A content delivery network places content near users through distributed edge locations.

## What to understand

Understand origin versus edge, cache keys, expiry, invalidation, and cacheable responses.

## Think through this example

A versioned course image can be served near a student rather than repeatedly from the origin.

## Common mistake

Publicly caching private personalized responses.

## Practice yourself

Draw the first-request and cache-hit paths and plan a new asset release.

Write your own implementation in `practice/` when ready. No solution or starter code is supplied.
