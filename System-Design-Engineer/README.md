# System Design Engineer

HLD decides how major components cooperate and scale. LLD decides how responsibilities, interfaces, objects, and state transitions work inside those components.

- [HLD — 20 screenshot concepts](HLD/README.md)
- [LLD — 20 screenshot concepts](LLD/README.md)

Study LLD after Python OOP and a small API. Study HLD after HTTP, SQL, and one complete application. In a design exercise, clarify requirements and major components first, then work down to interfaces and details.

Each concept has notes and a practice space. Connect both levels in the [capstone](../Capstone-Project/README.md).
